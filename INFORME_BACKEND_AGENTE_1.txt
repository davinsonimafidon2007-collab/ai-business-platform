1. RESUMEN EJECUTIVO
===============================================================================

El proyecto es una aplicación FastAPI (`app/main.py`) con arquitectura modular:
- API v1 (`app/api/v1/`): auth, admin, budget_search, dashboard, deals, health,
  inspection, mobile, notifications, opportunities, routes (search/vehicles/health),
  searches, search_orders, users, vehicles.
- Core (`app/core/`): config, redis, exception_handlers, firebase, limits, logging.
- Middleware (`app/middleware/`): auth, logging, rate_limit, request_id.
- Database (`app/database/`): DatabaseManager, session.
- Dependencies (`app/dependencies/`): auth (JWT + API Key + auth_disabled bypass).
- Services (`app/services/`): auth_service, search_engine, search_orchestrator,
  opportunity_finder, evaluation_engine, deal_service, inspection_service,
  comparable_market_estimator, profit_analyzer, etc.
- Repositories (`app/repositories/`): repositorios async SQLAlchemy para todos
  los modelos principales (user, search, vehicle, deal, inspection, etc.).
- Providers (`app/providers/`): autoscout24, autoscout24_es, mobile_de,
  openai_vision, gemini_vision, base, registry, fixtures (coches_net, es_market).
- Jobs (`app/jobs/`): scheduler, process_search_orders, provider_canary,
  refresh_opportunities, cleanup, base, factory.
- Agents (`app/agents/`): alert_agent, budget_search_agent, negotiation_agent,
  opportunity_agent, scoring_agent, search_agent, re_scoring_agent.
- Scripts (`scripts/`): smoke tests (as24_live, critical_path, es_providers),
  backup/restore postgres, check_integrations_ready, release_check.

Estado general: la aplicación está COMPLETA en estructura y código funcional.
No se detectaron archivos rotos ni sintaxis inválida. Hay evidencia de tests
unitarios e integrados para casi todos los módulos críticos. El proyecto no es
mock puro: los endpoints llaman a servicios reales que usan repositorios async
y providers HTTP. Algunos paths (como `tests/unit/test_search_engine.py`) no
existen, pero el orquestador (`search_orchestrator.py`) está cubierto por
`tests/unit/test_search_orchestrator.py`. Hay un subdirectorio `ai-business-platform-clone/`
que parece ser una copia/clon del mismo proyecto; no se auditó como parte del
raíz solicitado.
